# Requirements Doc Counting Calculator 


## Overview 

- An Application to Streamline counting cash in my job insteading of using the standard calculator app use this it's similar to the spreadsheets used at work but allows for quicker tmux like navigation between text boxes 

## Problem 

- when using the standard calculator app you need to calculate the amount of money in your head while adding it to the calculator and if you make a mistake it's hard to tell where you went wrong this application is designed to make the process easier for me and others with a counting service and a clean ui to help 


## Goals
- add functionailty to manage coin rolls can allow you to easy minus 50, 25, 10, 5 and 2 based 
- reduce navigation time moving between money options 
- Automatically do the multiplication for me so i can count everything by one which is much easier then by 5 or by 20 


## Target User 
- Me specfically but can expand to other people in my workplace if i think the application is really good
